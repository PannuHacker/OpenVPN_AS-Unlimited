## 📦 Features

- ✅ One-line installation
- ✅ No user count restriction (upto 1024)
- ✅ Based on stable CentOS 7
- ✅ Auto-configured services

---

## 🧰 Requirements

- 🐧 CentOS 7 (bare-metal or VM)
- 🧑‍💻 Root or sudo privileges
- 🌐 Internet connection

- ✅ AWS EC2 t2.micro (CentOS-7)
